# GitHub repository and local folder

These steps are phase 7. Do them after the rename is committed and pushed, so that one commit holds the complete change.

The new names are in `01-names.md` §1: repository `tillg/cardxchange`, folder `~/git/cardxchange`.

## 1. GitHub repository

### 1.1 Rename

1. Open the repository on GitHub, then **Settings**, **General**, **Repository name**.
2. Enter `cardxchange` and select **Rename**.

Or from the folder: `gh repo rename cardxchange`.

What GitHub does:

- Issues, stars, watchers and the wiki stay.
- The old web address and the old git address redirect to the new ones.
- The redirect stops if a new repository with the name `pplz` is created in the same account. Do not create one.

### 1.2 After the rename

1. Set the remote: `git remote set-url origin https://github.com/tillg/cardxchange.git`. `gh repo rename` does this itself for the folder where it runs.
2. Check: `git remote -v` and `git fetch`.
3. On the repository page, select the gear next to **About**:
   - Description: one sentence with the name cardXchange.
   - Website: `https://cardxchange.me`.
4. **Settings**, **General**, **Social preview**: upload `assets/social-preview.png`. The file already shows the new name.
5. If GitHub Pages will serve `cardxchange.me`: that is a separate change (see `README.md` §3, not part of this change).

### 1.3 Places that name the repository

- No tracked file contains the repository address today.
- The request for the notes entitlement names a website. If that is the repository address, give Apple the new address together with the new bundle ID (`03-apple-guide.md`).
- Local clones on other machines: set the remote there too.

## 2. Local folder

### 2.1 Before the rename

1. Commit or stash all work. `git status` is clean.
2. End all Claude Code sessions, terminals, editors and Xcode windows that use the folder.
3. Quit the app. No `cx` process runs.
4. List worktrees: `git worktree list`. Remove the ones that are not needed.

### 2.2 Rename

```sh
mv ~/git/pplz ~/git/cardxchange
```

### 2.3 Repair what holds the old path

| Thing | Why it breaks | Repair |
|---|---|---|
| `.build/` | SwiftPM stores absolute paths | `rm -rf .build`, then `swift build` |
| The command on the PATH | the symlink `cx` points into the old `.build`; the symlink `pplz` is already deleted (phase 5) | `swift build -c release`; `ln -sf "$(swift build -c release --show-bin-path)/cx" ~/.local/bin/cx` |
| Generated Xcode project | regenerated by the scripts | delete `App/pplz.xcodeproj` and the old generated entitlement files if they are still there |
| Xcode derived data | keyed by the project path | delete the old `pplz-…` folder in `~/Library/Developer/Xcode/DerivedData/`; a build makes a new one |
| Git worktrees in `.worktrees/` | each worktree stores the path of the main folder | `git worktree repair` |
| Simulator for `scripts/ui.sh` | the script expects the name `cardxchange iPhone` | `xcrun simctl rename "pplz iPhone" "cardxchange iPhone"` |
| Shell profile | old variables and aliases | remove `PPLZ_STORE` and aliases for `pplz`; add `CX_STORE` only if it was set before |
| `private/` | ignored by git; it moves with the folder | no action |
| `tmp/` | throw-away data | delete it |

### 2.4 Claude Code

Claude Code keeps the memory and the session history of a project in a folder that is named after the project path.

| Old | New |
|---|---|
| `~/.claude/projects/-Users-<user>-git-pplz/` | `~/.claude/projects/-Users-<user>-git-cardxchange/` |

1. Rename that folder with `mv` when no session runs. The memory files (for example the reminder for the notes entitlement request) are then available in the new folder.
2. Start Claude Code with `scripts/claude.sh` from the new folder.
3. In the first session, ask Claude to read `MEMORY.md` and to correct each memory that names the old name, the old path or the old bundle ID.
4. Settings that name the old path (permission rules in `~/.claude/settings.json` or `.claude/settings.local.json`, additional working folders): search for `git/pplz` and correct them.

### 2.5 Check

- `git status` and `git fetch` work in `~/git/cardxchange`.
- `swift build` and `swift test` pass.
- `cx --help` works from a different folder.
- `scripts/build-app.sh mac` installs `/Applications/cardXchange.app`.
- `grep -rn "git/pplz" ~/.zshrc ~/.zprofile ~/.claude/settings.json` finds nothing.
